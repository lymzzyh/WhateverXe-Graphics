# UHD770 source builds

The `UHD770` branches combine the guarded WEX adaptations with the current
Graphics package. [uhd770-source.json](uhd770-source.json) pins the WEX source
commit; no floating branch is used as a build dependency.

Prepare WEX's public Lilu and MacKernelSDK dependencies as described in its
`docs/UHD770.md`. Use a clean checkout at the pinned revision. On macOS with
Xcode Command Line Tools, Python 3.10+, Node.js and `rcodesign` 0.29.0:

```sh
python3 tools/build_uhd770.py --wex-source ../WhateverXe --verify
```

Use `--sdk`, `--lilu`, `--output` or `--rcodesign` for alternate paths. Omitting
`--verify` builds both WEX configurations and the package without running the
CPU and final-package test suites. The source trees must be clean so that the
recorded revisions identify the code used.

The default `dist/UHD770/` output contains:

- `DEBUG/` and `RELEASE/`: WEX and development Compat built from source, debug
  symbols, stack checks and source/hash manifests.
- `Graphics/`: the standard Graphics package, payload manifest and SHA256SUMS.
- `source-build.json`: both repository revisions, WEX source manifests, the
  package hash and whether verification was run.

WEX is built from source without private Apple input pages. Graphics is
repackaged from the complete signed assets already in this repository. Apple
driver/compiler binaries and the private Mod signatures cannot be recreated
from these repositories alone. The generated development Compat is never
substituted into the package. See [SOURCES.md](SOURCES.md) for payload provenance.

This command does not install the package, change EFI, or reboot. CPU, ABI,
dependency and signature checks do not prove hardware stability. The optional
UHD 770 mitigations remain experimental; using newer Graphics does not remove
their exact device/kernel/page guards.
